# External technical references

- MegaManZeroRecomp: https://github.com/mstan/MegaManZeroRecomp
  - useful for function boundaries, ROM identity and GBA-side behavior
  - not copied into this project

- GBARecomp: https://github.com/mstan/gbarecomp
  - useful as a reference for ARM/Thumb control-flow and hardware-facing behavior

- PS2SDK: https://ps2dev.github.io/ps2sdk/
  - target SDK and EE/IOP interfaces

- gsKit: https://github.com/ps2dev/gsKit
  - Graphics Synthesizer interface used by the renderer foundation

The PS2 project is intended to remain an independent native implementation.
